## 跨模态匹配效果

### 成功案例 1：非精确匹配

```
Query: "残差网络解决梯度消失"  → 论文中并无原文出现"解决梯度消失"字样
Top 1: resnet-paper.pdf 第8张图 "残差网络的skip connection结构图"
→ 跨模态语义匹配成功，跳过了精确文本匹配的限制
```

### 成功案例 2：图片内容理解

```
Query: "Transformer架构图"
Top 1: attention-paper.pdf 第3张图 "Transformer模型整体架构示意图
       (编码器-解码器结构、多头注意力、位置编码)"
→ 从论文最开头找到了最相关的架构图，而非后面的推导页面
```

### 成功案例 3：中文查询匹配英文论文

```
Query: "GPT-3的few-shot学习" (中文)
Top 1: gpt3-paper.pdf 第20张图 "GPT-3的few-shot/in-context learning实验设置"
→ 中文查询成功匹配英文论文中的图片描述
```

## 三路检索贡献分析

| 检索路径 | 平均返回数 | 说明 |
|----------|-----------|------|
| Milvus 文本向量 (bge-m3) | 20 | 文本语义匹配 |
| Elasticsearch BM25 | 20 | 关键词精确匹配 |
| Milvus 图片向量 (Qwen3-VL) | 20 | 跨模态图片匹配 |
| **RRF 融合后** | **~52** | 三路去重融合 |

图片描述内容（`[图片描述]` chunk）作为文本同时出现在文本向量和 BM25 索引中；跨模态 VL 向量在 4096 维空间中独立匹配，产生独立于文本的检索结果。

## 局限性与改进方向

| 问题 | 现状 | 改进 |
|------|------|------|
| VL 图片编码 | 使用描述文本编码（非原始图片） | 图片压缩到 256px 后直接编码跨模态向量 |
| 图片检索分数偏低 | Top1 仅 0.016~0.033 | 增加图片向量权重或调整 RRF k 值 |
| 并发处理慢 | 66 张图片串行 caption + embedding | 并行处理 |
| 检索耗时 | 平均 1.48s (含 VL embedding API) | VL embedding 缓存 |

## 结论

三级跨模态 RAG 原型验证成功：
1. **图片提取**：PDFBox 从 66 页 PDF 中正确提取了所有页面图像
2. **图片理解**：Qwen3-VL 生成的描述准确识别了图表类型和内容
3. **跨模态检索**：4/5 的查询中 Top1 结果来自图片描述 chunk，证明跨模态通道有效
4. **端到端可用**：从论文上传到语义检索的完整链路可运行
