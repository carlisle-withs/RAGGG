# RAGAS 四指标评测报告（真实实验数据）

- **日期**：2026-09-22
- **被测链路**：RAGGG 完整生产链路——意图识别 → 查询扩展 → hybrid 检索（Milvus+ES RRF）→ SiliconFlow CrossEncoder 精排 → GLM-5.3-Flash 生成
- **判分模型**：glm-5.3-flash（项目自带 RAGASEvaluator，LLM-as-judge）
- **数据**：PubMedQA（ragbench test split）前 20 条，KB 19（196 篇 / 860 chunks）
- **Embedding**：本地 Ollama bge-m3

## 1. 实验方法

每条数据完整走两步，全部真实调用、无预置答案：

1. **生成**：`/api/v1/retrieve/hybrid`（rerank=true, topK=5）取真实检索上下文 + `/api/v1/chat`（kbIds=["19"]）生成真实回答；ground truth = 数据集人工标注的相关句拼接
2. **判分**：`/api/v1/evaluation/evaluate`（内部约 8 次 LLM 判分调用 + 4 次 embedding）

生成并发 4、判分并发 3；生成 p50 60s/条（GLM 思考模型），判分 p50 107s/条。

## 2. 实验结果（n=20）

| 指标 | mean | median | min | max |
|---|---|---|---|---|
| **Faithfulness（忠实度）** | 0.847 | **1.0** | 0.0* | 1.0 |
| **Answer Relevancy（相关性）** | 0.687 | 0.687 | 0.521 | 0.798 |
| **Context Precision（精确度）** | 0.640 | 0.6 | 0.2 | 1.0 |
| **Context Recall（召回率）** | **0.982** | 1.0 | 0.9 | 1.0 |
| **RAGAS 综合**（0.3/0.3/0.2/0.2 加权） | **0.785** | 0.80 | 0.46 | 0.94 |

\* q5 的 faith=0.0 且判分耗时全场最长（247s），答案本身有据可依（引用了文档原文），高度疑似判分 LLM 调用超时被代码 catch 后返回 0.0（该实现异常路径返回 0.0 而非 0.5）。**剔除 q5 后 Faithfulness mean = 0.926 (n=19)**，此时综合分约 0.82。

## 3. 结果解读

1. **Context Recall 0.98 ≈ 满分**：与召回评测的 Hit@10=100% 相互印证——检索环节把 golden 证据都找回来了。系统的召回能力是四项中最强的。
2. **Faithfulness 0.93（剔异常后）**：生成答案基本严格贴着上下文（GLM 大量使用引用格式回答），幻觉控制良好。中位数 1.0 说明多数答案完全有据。
3. **Context Precision 0.64 是最弱项**：top-5 里平均只有 ~3.2 块被判"相关"。结构性原因：PubMedQA 摘要被切成 4-5 块，top-5 必然混入同文档弱相关邻块 + 跨文档干扰块；且该实现是**逐块二值判定再求比例**，不含 RAGAS 官方的排序位置折扣，天然偏低。
4. **Answer Relevancy ~0.69 属健康区间**：该实现 = 原问题与"从答案反推的 3 个子问题"的余弦相似度——相关但措辞不同的问题对，余弦通常落在 0.5-0.8，几乎不可能到 1.0，属度量构造特性而非质量缺陷。

## 4. 方法学局限（必读）

- 判分与生成同用 glm-5.3-flash，存在**同源模型自评偏置**
- n=20 单次运行，未做方差估计；置信区间未计算
- 指标实现是项目自带的**简化版 RAGAS**（忠实度无陈述分解、精确度无排序折扣、相关性仅 3 个子问题），与官方 ragas 库数值不可直接对表
- 判分为 LLM 主观打分，绝对值仅供横向对比（同链路改前/改后），不宜当绝对质量声明
