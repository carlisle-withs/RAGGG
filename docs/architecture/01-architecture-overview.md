# RAGGG 架构设计文档

> 本文档描述 RAGGG 智能对话平台的完整架构设计，包括已实现模块和待实现模块的详细规划。

## 一、项目概述

### 1.1 项目背景

针对实验室内部非结构化文档（知识库规模5000+篇），构建一站式RAG平台。通过打通知识库构建、多路检索召回、以及LLM动态上下文处理的全链路，支持多轮会话处理、分层评测体系及限流等机制，达到企业级应用标准。

### 1.2 技术选型

| 组件 | 技术 | 版本 |
|------|------|------|
| 后端框架 | Spring Boot | 3.2.4 |
| AI/LLM框架 | LangChain4J | 0.36.0 |
| 向量数据库 | Milvus | 2.6.6 |
| 全文搜索引擎 | Elasticsearch | 8.15.0 |
| 消息队列 | Apache Kafka | 3.7.0 |
| 对象存储 | MinIO | - |
| 关系数据库 | MySQL | 8.4.0 |
| 缓存/会话 | Redis | 7 |
| 文档解析 | Apache Tika | 2.9.2 |
| 安全认证 | Spring Security + JWT | - |

**语义去重算法：**

```python
def deduplicate(messages):
    """基于语义相似度的去重"""
    if len(messages) < 2:
        return messages

    embeddings = [embed(m.content) for m in messages]
    keep_indices = [0]

    for i in range(1, len(messages)):
        is_duplicate = False
        for j in keep_indices:
            similarity = cosine_similarity(embeddings[i], embeddings[j])
            if similarity > DEDUP_THRESHOLD:  # 0.9
                is_duplicate = True
                break
        if not is_duplicate:
            keep_indices.append(i)

    return [messages[i] for i in keep_indices]
```

**轨迹审计：**

```python
def detect_loop(messages, current_query):
    """检测死循环：连续相同意图的重复检索"""
    recent = messages[-6:]  # 最近3轮对话

    # 检查最近3轮是否都是 FACTUAL 类型且查询相似
    if len(recent) >= 6 and all(m.intent == 'FACTUAL' for m in recent[::2]):
        # 计算与当前查询的相似度
        for i in range(0, len(recent)-2, 2):
            if cosine_similarity(embed(current_query), embed(recent[i].content)) > 0.95:
                return True  # 检测到重复检索
    return False
```
